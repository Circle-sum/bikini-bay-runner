# 地铁跑酷 · 比基尼湾站

海底环线跑酷小游戏。三条轨道、四位跑者、四种绝活，无限旅程挑战最高分；同一台电脑还能拉上朋友来一局双人对战，
主菜单的**小世界**里可以走进一片海湾，下水撒网抓水母换果冻与贝壳币。
纯 Canvas 2D 手写伪 3D 渲染，零框架、零运行时依赖——本地直接打开 `index.html` 就能玩。

## 玩法

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 换道 | `←` `→` / `A` `D` | 左右滑动 |
| 跳跃 | `↑` / `W` | 上滑 |
| 翻滚 | `↓` / `S` | 下滑 |
| 冲浪板（4 秒无敌，每局一次） | `空格` | 双击 / 点按按钮 |
| 角色技能（每局一次） | `E` | 点按按钮 |
| 暂停 / 继续 | `P` / `Esc` | 右上角暂停键 |

- 珊瑚、木桶、船锚、水母 → **跳过去**；海草帘、船舵牌 → **翻滚钻过去**；迎面驶来的列车 → **提前换道**，静止列车可以跳上车顶。
- 每局三个挑战（300 米 / 30 金币 / 15 连击）各 +500 分、结算各 +20 贝壳币；每枚金币结算为 1 贝壳币。
- 贝壳币可在海底商店买滑板外观、角色装饰、复活券和开局道具。
- 每 250 米进入一个新街区，四个街区（菠萝街 / 蟹堡码头 / 水母田 / 穹顶实验区）各自有独立配色、地标与背景音乐，顺序每局洗牌且不连续重复；每三个街区会夹一段**深海夜色**。

### 成长与进度

- **角色解锁**：开局只有海绵碧莲免费，其余三位用贝壳币解锁（派宝宝 180 / 章鱼王哥 320 / 诸葛珊迪 520）。
  选人界面里锁定角色仍可点开预览技能，钱包够时「出发」键会变成「解锁」。
- **成就徽章墙**：16 个成就（跑酷 12 + 水母田 4：第一网 / 单局 18 果冻 / 3 只黄金水母 / 累计 100 只），达成即发贝壳币奖励，解锁后永久保留。
- **生涯统计**：总局数、累计距离 / 金币、最高分与最高连击、单局最多金币、复活次数、到访街区、抓水母局数 / 累计捕获 / 单局最佳 / 黄金水母、解锁与成就进度。
- **设置**：背景音乐 / 音效独立音量、画面质量（自动 / 高 2x / 中 1.5x / 低 1.25x）、碰撞震动开关、清空进度。
  设置单独存一个 key，改音量不会影响经济存档。

入口都在标题页（成就 / 生涯 / 设置），设置也可以从暂停菜单进入。

### 双人对战（同屏，一台电脑）

标题页「双人对战」进入。两人共用一条赛道同时开跑，一人一面键盘：

| 玩家 | 移动 | 道具 | 开局站位 |
| --- | --- | --- | --- |
| 玩家 1 | 方向键 | `/` | 右道 |
| 玩家 2 | `W` `A` `S` `D` | `Q` | 左道 |

- 每人 **3 条命**：撞到障碍掉 1 条命并清空连击、进入约 1 秒无敌；**先掉光命的一方输**。
- 两人共用一条赛道、各自站一边（左手 WASD 在左、右手方向键在右），互不阻挡。
- 赛道上会随机刷出 **🍔 汉堡包**（补 1 条命，最多 3 条）和三种**道具**：
  - **🐙 章鱼**：把对手拽回你身边——他领先就拉回同一水平线，否则再往后推一段；
  - **🥄 铁锹**：敲晕对手使其减速，贴身时晕得更久（离得远也照样能用）；
  - **👟 极速鞋**：捡到**立即**冲刺一段，不占道具槽。
  道具槽只保留**最新**拿到的那一个：捡到新道具会直接替换旧的；章鱼 / 铁锹按各自的键手动使用。
  三种道具**永远可用**，两人同持同一种也不会互相抵消。
- 只保留换道 / 跳跃 / 翻滚，不带角色技能和冲浪板；**金币先到先得、吃到即消失**，
  同一枚补给被两人同时够到时由更靠近的人先拿到（完全并列则两人交替），
  金币**不写入经济存档与生涯统计**。
- 相机跟两人中点、并随两人间距自动后撤，领先太多还会被「收油」，保证两人始终都在画面里；同一条车道允许重叠。

### 小世界（可走动的海湾 · 撒网抓水母）

标题页「小世界」进入一片俯视海湾：西边是沙滩，东边浅水就是**水母田**。
**蟹堡王**与**空手道棚**立在沙滩上，但还在装修中（可以走近打招呼，不能进）。

- **走动**：`WASD` / 方向键按住走；触屏点地走路、按住拖动朝那个方向走。镜头缓动跟随，
  建筑和海岸线都会挡人。
- **走进浅水就开始抓水母**：同一张地图、同一个镜头，没有加载、没有切场景。涨潮 45 秒后自动上岸结算。
- **撒网**：鼠标点哪撒哪、触屏点按、键盘空格——网飞出去落网，罩住落点一圈（半径 84）的水母，
  一网可以抓多只；撒空会清空连抓。最远撒 300 距离，冷却 0.62 秒。
- **诱饵**：每局 3 个，丢在脚边 5 秒，把附近的水母（连电水母）引过来聚团，再一网收。
  这是「连抓」的起手——聚得越多，第 5 / 10 / 15 连的 ×1.5 / ×2 / ×3 来得越快。
- 粉水母 1 果冻、蓝水母 2、黄金水母 5；绿**电水母**抓不得——网到或撞到都会短路 2 秒并清空连抓。
- 收网时果冻按 1:1 换贝壳币，一网没被电到且抓到 6 只以上再赏 12 贝壳币（「完美一网」）。
- 四位跑者的手感不同：碧莲撒网快（0.44 秒冷却）、派宝宝的网更大（×1.25）、
  王哥让水母慢 20%、珊迪能在水母头顶看到价签。
- 键盘 `E` / `空格` 和建筑说话，`C` 换人，`Esc` 回标题页。
- 果冻库存、局数、累计捕获、单局最佳与黄金水母数都写进**同一份经济存档**（`bbSubwayEconomyV1` 的 `world` 字段），
  和贝壳币一起持久化，写盘失败也一起回滚。
- 没有每日上限或防刷限制：单局 45 秒 + 单只低单价，天然把一局收益压在 10~30 果冻。

### 四位跑者

| 跑者 | 技能 | 说明 |
| --- | --- | --- |
| 海绵碧莲 | 金光护体（被动） | 每局抵挡首次碰撞，并获得 1.5 秒保护 |
| 派宝宝 | 一铲开路（主动） | 清除当前轨道前方最近的一个路障 / 横杆 / 水母 |
| 章鱼王哥 | 触手慢调（主动） | 前进速度与迎面列车减速 40%，持续 4 秒 |
| 诸葛珊迪 | 穹顶推演（主动） | 显示前方安全轨道或动作提示 5 秒；连击保留 3.4 秒 |

### 深海事件（单人 / 对战都会遇到）

- **🌀 漩涡错位**：随机 20~45 秒出现一次，持续 4 秒。镜头把整个海底世界**翻滚到 90° 再转回来**，
  同时**左右操作颠倒**（键盘与滑动一起翻），HUD 有「左右颠倒 x.x s」提示。
- **🚆 车顶二层赛道**：静止列车顶上铺了一条金币链，长车还会在车尾放一个**车顶路障**；
  跳上车顶吃到金币后，得再跳一次躲开路障。
- **🎥 抬高视角**：站上车顶或被喷气背包带着飞时，镜头会**整体抬高并微微俯视**（天际线上移，
  露出更多前方轨道），落地后再缓动落回原来的机位——不会一帧跳变。
- **🌙 深海夜色**：每三个街区插一段夜航（第 3、6、9… 个街区），环境色整体压暗、
  金币带荧光；进出夜色各有 25 米平滑过渡，不会硬切。
- **✨ 完美穿越**：同一条道里跳过 / 翻滚躲开障碍就累计一次**险过**，攒满 6 次给
  **6 秒双倍金币分 + 2 秒无敌**，HUD 会显示「险过 x/6」。
- **🫧 连击变身**：连击 15 给**泡泡护甲**（挡下一次撞击后消失），连击 30 再叠加**鱼鳍疾行**
  （护甲 + 提速 20%）；同一条连击链里每档只触发一次，连击断了才能重拿。
- **🎴 随机事件卡**：每换一个街区抽一张，影响接下来的 250 米——
  金币雨（金币分 ×1.5）、水母潮（水母更密 + 金币分 ×1.5）、顺流（速度 +12%）、
  逆流（速度 −12% / 金币分 ×1.6）、电闪雷鸣（天色转暗 + 金币分 ×1.5）、风平浪静。

漩涡与事件卡在**双人对战里同样生效**——颠倒的那 4 秒里两个人的左右都是反的，
道具和金币的收益也会被事件卡放大。

## 本地运行

```bash
npm start          # http://127.0.0.1:4173
```

没有依赖也能跑：随便一个静态服务器指向仓库根目录即可（`python -m http.server` 也行）。
只有跑测试才需要 `npm install`。

## 优化的效果（同机实测）

| 指标 | 改动前 | 改动后 |
| --- | --- | --- |
| 固定负载 2000 帧的循环耗时 | 2382 / 2436ms | 2202 / 2233ms（**−8%**） |
| 每 2000 帧的强制 GC 耗时 | 11.3 / 11.2ms | 10.0 / 10.0ms（**−11%**） |
| 暂停 / 结算时 2 秒内的整屏重绘 | 120 / 121 次 | **1 次** |
| 首屏需下载（HTML + CSS + JS + 四张立绘） | 686KB | 477KB（**−30%**） |
| 其中角色立绘 | 528KB（PNG） | 319KB（无损 WebP，**−40%**） |
| 部署包 `dist/` | — | 617KB（含只在安装时才取的 PWA 图标） |

测量方式：`_verify/gcprobe.cjs`（固定道具集、固定循环次数、`--expose-gc` 强制回收计时）与
`_verify/perf.cjs`（render / update 微基准 + rAF 帧间隔 + 暂停态重绘计数）。
注：本机 Chrome 以软件光栅化运行，绝对帧率不代表真机，以上均为同机前后对比值。

暂停态重绘从 120 次降到 1 次，是因为原来暂停时每帧仍在重画整屏——画面明明是静止的。

## 部署

推送到 `main` 会先跑 `npm test`，通过后用 `scripts/build-dist.cjs` 只把运行时文件打进
`dist/`（index.html、sw.js、manifest、`assets/ui.css`、角色立绘、图标）再发布到 GitHub Pages。
仓库里的设计稿、调试导出和预览图不进部署包。

## 技术要点

- **伪 3D 投影**：世界用 `(x, y, z)` 描述，`project()` 做单点透视投影到 2D 画布；
  `box3D()` 用近远两个截面拼出长方体。所有场景元素都是投影后直接画的矢量图形，
  没有贴图也没有 3D 引擎。
- **深度排序**：每帧按 `z` 从远到近排序后依次绘制，复用同一个数组避免每帧新建副本。
- **街区系统**：`districtPaletteAt()` 在边界前 35 米把两套配色调色板做线性插值，
  所以换街区是渐变而不是硬切。
- **音频**：全部用 Web Audio 现场合成（振荡器 + 噪声 buffer），没有音频文件。
  四个街区各有一段 32 步循环（调式 / BPM / 镲点不同），换街区时只切换音符来源、音序器不中断，
  听感像自然转调；背景音乐与音效走两条独立增益，音量在设置里分别可调。
- **存档分层**：经济 / 进度（`bbSubwayEconomyV1`：钱包、滑板、解锁、成就、生涯统计、水母田的果冻与捕获记录）
  与设置（`bbSubwaySettingsV1`）分开存；`persistEconomy` 写盘失败会整体回滚内存，
  设置放另一把 key 就不会被经济回滚牵连。
- **性能策略**：
  - 渐变对象按参数缓存，只在街区过渡时重建（原来每帧新建 7 个 `CanvasGradient`）；
  - `shade()` / `tint()` 结果做字符串缓存（原来每帧上百次 `parseInt` + 拼串）；
  - HUD 更新先在内存里比对再写 DOM（原来每帧读 `innerHTML` 做比较）；
  - 道具数组原地压缩，不再每帧 `filter()` 出新数组；
  - 暂停 / 结算画面静止，只在状态切换或窗口尺寸变化时重绘一次，不再每帧重画整屏；
  - 手机上 3x 屏按 2x 渲染；「自动」画质下连续掉帧时分辨率单向降级到 1.5x / 1.25x，手动选档则固定住。
- **双人对战复用单人引擎**：世界生成、`project()` 投影、碰撞谓词、音频全部共用，
  只把重力等少数函数改成接受「跑者」参数（默认是单人主角），单人调用点原样不变；
  两名跑者各持一套状态（命数 / 道具 / 连击 / 分数），相机取两人中点并轻微拉远。
- **深海事件层都是「渲染期改造」**：夜色不改世界数据，而是按 `segment % 3 === 2` 生成一套压暗版
  调色板（按色板身份 + 量化后的浓度缓存，和渐变缓存共用命中）；漩涡只在 `renderWorld` 里对整块画布
  做一次 `rotate`，四角用当前街区的深海渐变垫底；抬高视角也只是改相机高度与天际线，地形数据不动。
  `districtPaletteAt()` 本身**没有被改动**，所以街区配色的回归断言依旧成立。
- **小世界是「同一张地图上的第二模式」**：海湾（沙滩 + 浅水）是一套独立的俯视 Canvas 图层
  （`WorldHub`），自己一套世界坐标、碰撞（沙地块并集 / 椭圆潟湖）与镜头缓动；
  抓水母（`JellyGame`）不另开场景，只是在这张地图上叠加水母、网与诱饵，
  由 `WorldHub.render()` 分层调用（`drawUnder` / `drawOver` / `drawScreen`），玩家始终画在水母之上。
  两个模式都在 `assets/world/world.js` 里，`index.html` 只接状态机（`world` / `jelly` / `jellyPause` / `jellyOver`）、DOM 与存档。

## 已知取舍

- `* { letter-spacing: 0 !important }` 关掉了早期设计里的字距，后面又逐条用 `!important` 加回来。
  它当前是「生效」样式的一部分，想恢复字距要先删掉这条全局规则并逐个确认。
- 横牌（`gate`）除了翻滚，也可以在跳跃顶点（`p.y ≥ 2.3`）飞过去，窗口约 0.27 秒，
  比翻滚的 0.55 秒更严格。如果设计意图是「横牌必须翻滚」，需要把这条路径封掉。
- 角色立绘用**无损** WebP（解码后与 PNG 逐像素一致，体积 −40%）。
  更激进的有损 q95 可以再省 200KB，但选择界面上立绘接近 1:1 显示，
  有损版本会在那里产生约 0.2% 像素的可见差异，因此没有采用。
- 选择界面的角色卡缩略图（显示尺寸约 30px）仍用同一张大图缩放，
  在极小的缩略图上 Chrome 对 PNG / WebP 的降采样结果会有亚像素差别。
  源图数据本身逐像素一致，属于浏览器侧差异。
- 仓库里还留着设计阶段的原图（`assets/chars/tight/`、`_debug/`、`preview_*.png`、
  `assets/raw/`），它们不进部署包但会占仓库体积，要清理可以直接删（都在 git 历史里）。
- 双人对战目前只支持键盘（一台电脑、两人各用半边键盘），触屏双人（分屏或轮换）还没有做；
  道具键用了 `/` 与 `Q` 这对左右手都好按的键，换键只需改 `VS_ITEM_KEYS`。
- 小世界只开放水母田，蟹堡王与空手道棚在沙滩上是「装修中」实体（能走近、能打招呼、不能进入）；
  果冻目前只作为库存与成就计数，还没有可消费的出口。
  设计稿 §9 的开放问题（蟹黄包的正式定名、地点开启费用、电水母惩罚强度、地点角标）留到后续版本再定。
